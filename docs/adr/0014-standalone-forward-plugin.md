# 转发功能独立成插件，使用主程序发送记录进入上下文

本文件记录规格驱动阶段一的已确认目标、源码事实与待决策项；不是实施授权，不取代当前运行规格。现有 `0013-refactor-scope-research.md` 保持原样，其“协议直发后补注入”的建议不符合本次新要求。

## 已确认目标

- 已确认插件名“麦麦搬运喵”，目录为 `/Users/arcdent/github/SmallProjects/maimai-courier-plugin/`；已创建术语表和 ADR，尚无业务实现。
- 同时保留自动转发和工具转发，允许破坏性重构以简化实现。
- 向 Maisaka 暴露转发工具，公开输入为源消息 ID 和目标群聊 ID；一次调用投递给指定群。
- 自动入口只处理合并转发卡片；工具入口还支持普通文字、图片等单条消息。不支持的类型明确报错，不静默丢段后宣称成功。具体支持矩阵须随发送链核实。
- 自动路径由源群 Maisaka 判断是否值得分享，再调用同一个两参数工具；不掷骰，不保留目标群决策票。这里的“自动”指无需群友明确请求，源群收到合并转发后可由 Maisaka 自主决定转发，不沿用旧术语中的概率语义。
- 自动与工具共用源群、目标群白名单。工具只允许转发调用所在源群的消息，目标必须在配置的目标白名单中；模型不能通过参数绕过消息归属和白名单检查。
- 转发信息自然进入 Maisaka 上下文，不额外调用插件上下文注入接口。
- 同步本地 runbook；新目录首次创建 runbook 时先确认文件清单。阶段一不复制运行配置、凭证或业务代码。
- 已有未提交的测试变更和 ADR 0013 调研草案不覆盖、不回滚。
